# 香澄 · 水杉输入法皮肤

适配水杉输入法 Windows v0.11.1 的自定义原生皮肤。当前皮肤版本为 **v0.5.6**，包含吉他摆动与三色打字星星，仍作为早期预览发布。

**[下载 Windows x64 安装包](https://github.com/chafukuu/kasumi-metasequoia-skin/releases/tag/v0.5.6)** · **[下载与使用说明](docs/下载与使用.md)** · **[星星参数与图片接口](docs/星星参数与图片接口.md)** · **[开发与构建](docs/开发与构建.md)**

## 当前效果

- 原图保持固定比例，左侧吉他和飘带尽量固定；长度由右侧人物移动和遮挡控制。
- 整体采用较紧凑的尺寸，右侧人物独立缩小并上移。
- 双品丝精确跟随真实候选边界，与文字在同一帧绘制。
- 背景、人物、文字和品丝全部由同一个原生窗口绘制，一起出现和消失；无需驻留伴随程序。
- 七个候选保持单行。超长候选显示省略号，选中时仍提交完整内容。
- 吉他沿用 v0.5.4 的 ±8°、1.5 秒周期摆动，人物、飘带及候选排版保持不变。
- 每连续新增两个被接受字符，从琴身发出两颗随机抛物星星；宽 19–23 DIP，平滑淡入淡出。
- 蓝色 : 品红 : 黄色 = **2 : 1 : 1**，每组四颗打乱顺序，包含两蓝、一品红、一黄。蓝图与原品红图同为 114×136 像素，轮廓、尺寸、alpha 与白色细节一致，只有 RGB 颜色变化。
- 删除或其他编辑操作只清除未完成的两字符计数，已发出的星星继续飞行至正常淡出；真正结束会话时仍正常清理。
- 动画继续使用原生 Direct2D 绘制，改进续帧调度、过载让步、失败重绘和图片缓存，减少不必要的停顿。

四帧 LiveSD 状态切换尚未接入本版。星星的大小、轨迹、时间和 PNG 路径可通过[皮肤参数](docs/星星参数与图片接口.md)调整，无需重新编译支持该接口的 Server。

## 快速安装

1. 安装并确认可以使用 [官方水杉输入法 v0.11.1](https://github.com/metasequoiaime/msime-windows/releases/tag/v0.11.1)。
2. 从本项目 Releases 下载 `kasumi-metasequoia-skin-v0.5.6-windows-x64.zip`，完整解压。
3. 双击 `Install.cmd`，按 Windows 提示授予管理员权限。
4. 等待安装与运行检查完成，再到记事本切换为水杉输入法测试。

本包包含匹配的自定义 Server 和皮肤。**仅复制皮肤目录不足以获得本版效果。** GitHub 的 “Source code” 压缩包用于开发；普通使用请下载上面的 Windows 安装包。

安装前会备份原本体、皮肤和配置；只合并本皮肤需要的设置，不替换词库或用户输入历史。安装失败会尝试自动恢复，手动回退见[使用说明](docs/下载与使用.md#回退)。

## 适用范围与验证

当前适配 Windows x64、水杉 v0.11.1 及安装器明确列出的本体哈希。未知版本会拒绝覆盖。

v0.5.6 已完成 448 步原生构建，32 组候选布局、12 组解析夹具及输入计数、粒子模型、动画调度三项测试通过。已安装的同一 Server 先后通过两次 30 秒健康检查，均无崩溃；用户反馈“效果不错”。蓝图换色校验和两份皮肤文件一致性校验通过。验证记录仍保留 `liveVisualVerified=false`：未测量真实输入法视觉帧率，不能据调度测试宣称恒定 60 FPS。

便携安装器没有在另一台全新电脑进行完整安装、回退演练。已安装版本的健康记录和便携安装器测试分别记录，详见[验证记录](docs/验证记录.md)。

自定义 Server 未签名，使用普通权限清单；管理员程序中的输入界面尚未验收。若提示缺少 VC++ 运行库，请使用[微软官方 v14 x64 可再发行组件](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)。
