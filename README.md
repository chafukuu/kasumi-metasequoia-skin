# 香澄 · 水杉输入法皮肤

适配水杉输入法 Windows v0.11.1 的早期自定义皮肤。当前皮肤版本为 **v0.5.3**。

**[下载 Windows x64 安装包](https://github.com/chafukuu/kasumi-metasequoia-skin/releases/tag/v0.5.3)** · **[下载与使用说明](docs/下载与使用.md)** · **[开发与构建](docs/开发与构建.md)**

## 当前效果

- 原图保持固定比例，左侧吉他和飘带尽量固定；长度由右侧人物移动和遮挡控制。
- 整体采用较紧凑的尺寸，右侧人物独立缩小并上移。
- 双品丝精确跟随真实候选边界，与文字在同一帧绘制。
- 背景、人物、文字和品丝全部由同一个原生窗口绘制，一起出现和消失；无需驻留伴随程序。
- 七个候选保持单行。超长候选显示省略号，选中时仍提交完整内容。

LiveSD 动画尚未接入本版。

## 快速安装

1. 安装并确认可以使用 [官方水杉输入法 v0.11.1](https://github.com/metasequoiaime/msime-windows/releases/tag/v0.11.1)。
2. 从本项目 Releases 下载 `kasumi-metasequoia-skin-v0.5.3-windows-x64.zip`，完整解压。
3. 双击 `Install.cmd`，按 Windows 提示授予管理员权限。
4. 等待安装与运行检查完成，再到记事本切换为水杉输入法测试。

本包包含匹配的自定义 Server 和皮肤。**仅复制皮肤目录不足以获得本版效果。** GitHub 的 “Source code” 压缩包用于开发；普通使用请下载上面的 Windows 安装包。

安装前会备份原本体、皮肤和配置；只合并本皮肤需要的设置，不替换词库或用户输入历史。安装失败会尝试自动恢复，手动回退见[使用说明](docs/下载与使用.md#回退)。

## 适用范围与验证

当前适配 Windows x64、水杉 v0.11.1 及安装器明确列出的本体哈希。未知版本会拒绝覆盖。

本机已验收真实候选显示、长句、品丝和同步显隐；定向布局检查 36/36，原生皮肤与几何检查 13/13。便携安装器通过语法、配置合并及隔离预检，尚未在另一台全新电脑进行完整安装、回退演练，因此作为早期预览发布。详见[验证记录](docs/验证记录.md)。

自定义 Server 未签名，使用普通权限清单；管理员程序中的输入界面尚未验收。若提示缺少 VC++ 运行库，请使用[微软官方 v14 x64 可再发行组件](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)。
