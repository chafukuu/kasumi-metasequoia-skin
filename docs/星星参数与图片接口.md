# 打字星星的参数与图片接口

本页对应 v0.5.7（沿用 v0.5.6 的星星接口）。所有外观参数在皮肤 `skin.toml` 的 `[candidate_window.typed_stars]` 表内。数字或图片路径修改不需要重新编译支持该接口的 Server；保存后使用设置中的“重新加载皮肤”或正常重启输入法，使配置与图片缓存重读。

仓库皮肤位于 `skin/kasumi-adaptive/skin.toml`；默认实际加载位置为 `%LOCALAPPDATA%\metasequoiaime\skins\kasumi-adaptive\skin.toml`。自定义数据目录以输入法的实际配置为准。仅修改下载包或仓库中的副本不会影响已安装的皮肤。

## 三色与触发规则

| 参数 | 本版值 | 作用 |
|---|---|---|
| `enabled` | `true` | 开关星星效果 |
| `yellow_image` | `assets/star_y.png` | 黄色星星 PNG |
| `pink_image` | `assets/star_m.png` | 品红星星 PNG；键名沿用 `pink_image` |
| `blue_image` | `assets/star_b.png` | v0.5.6 新增的可选蓝色星星 PNG |

配置蓝图后，每组四颗星星的颜色集合固定为两蓝、一品红、一黄，顺序随机打乱，因此跨完整组的蓝色 : 品红 : 黄色比例为 **2 : 1 : 1**。单次只发出两颗，不能以单次颜色判断完整组比例。权重由原生模型定义，没有 TOML 权重键。

每连续新增两个被接受字符发出两颗。删除、移动、翻页和异步刷新不计入新增字符。删除等编辑操作清空未完成配对的计数，但保留已发出的星星直至正常淡出；真正结束会话仍按原窗口生命周期清理。

蓝图将现有品红图的每个像素从 `(R,G,B,A)` 精确转换为 `(G,B,R,A)`。两图均为 114×136 像素，alpha 逐字节相同，轮廓、尺寸、透明边缘和白色细节完全一致。三色都按原 PNG 贴图绘制，只施加位置、等比例缩放、旋转和透明度。

旧皮肤未配置 `blue_image` 时保留原先品红、黄色双色行为。已配置时应提供有效的皮肤内 PNG；不要依赖缺失文件关闭蓝星。

## 运动与大小

下列参数沿用 v0.5.5；吉他摆动保持 v0.5.4 的 ±8°、1.5 秒周期。

| 参数 | 本版取值 | 用途 |
|---|---|---|
| `width_min_dip` / `width_max_dip` | `19` / `23` | 随机图片宽度，保持宽高比 |
| `origin_x_dip` / `origin_y_dip` | `66.51933701657458` / `22.570441988950278` | 琴身发射点 |
| `rise_min_dip` / `rise_max_dip` | `24` / `38` | 随机上抛弧高 |
| `end_x_min_dip` / `end_x_max_dip` | `18` / `94` | 随机左右落点，实际扣除完整星形旋转半径 |
| `end_y_min_dip` / `end_y_max_dip` | `96` / `108` | 随机终点中心 Y |
| `duration_min_ms` / `duration_max_ms` | `1200` / `1450` | 单颗生命期 |
| `fade_in_min_ms` / `fade_in_max_ms` | `90` / `130` | 随机淡入时长 |
| `fade_out_min_ms` / `fade_out_max_ms` | `260` / `360` | 随机淡出时长 |
| `rotation_min_deg` / `rotation_max_deg` | `-24` / `24` | 出生角度 |
| `spin_min_deg` / `spin_max_deg` | `-70` / `70` | 全程自转角度 |
| `pair_separation_dip` | `22` | 两颗终点的最小横向距离 |

坐标单位为 DIP，以原生候选卡片左上为原点，Y 向下。`min_x_dip=8`、`max_x_dip=107`、`min_y_dip=-100`、`max_y_dip=132` 约束旋转后的整颗星星；原生卡片高 96.5 DIP，包含人物和透明留白，不等于可见选词条厚度。终点 96–108 DIP 沿用原有下落范围，屏幕工作区边缘仍允许裁掉装饰。

最小值须不大于最大值，时长须为正，淡入与淡出最大时长之和应小于最短生命期。图片比例无法装进安全范围时关闭星星效果，不拉伸素材、不移动候选词。每颗出生时一次性采样并解出完整抛物线，飞行期间不重新抽取轨迹参数。

## 更换图片

透明 PNG 放入同一皮肤的 `assets/` 后，修改相应图片路径。路径必须是皮肤内相对 PNG 路径，不可使用绝对路径或 `..`。PNG 最大边为 16384 像素，通常无需接近上限。程序读取实际宽高比，不要添加手填比例参数。保留原图，并用新文件名保存自定义图，便于回退。

```toml
[candidate_window.typed_stars]
enabled = true
yellow_image = "assets/star_y.png"
pink_image = "assets/star_m.png"
blue_image = "assets/star_b.png"
width_min_dip = 19
width_max_dip = 23
end_y_min_dip = 96
end_y_max_dip = 108
```

示例只列常用键，应编辑现有表，不要重复创建同名 TOML 表。修改后必须重载，程序不会轮询文件。发布蓝图满足“只有颜色不同”的精确像素规则；自行换图后不再保证该规则。发布包内的清单用于完整性校验，直接修改包内容会使清单失效；自定义已安装皮肤前请保留备份。
