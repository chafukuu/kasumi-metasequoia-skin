# 来源与素材

水杉原生代码来自 [metasequoiaime/msime-windows](https://github.com/metasequoiaime/msime-windows)，基于 v0.11.1；完整对应修改源码位于 `native-source/`，差异补丁位于 `patches/`。上游 GPL-3.0、各第三方组件许可证与版权声明均保留。

原图由项目作者提供，角色为香澄。原图 SHA-256：

`c2c798cc2896c3c23a09ed24db5c926280616cda380d6aba6098ec0a499b25c4`

本版未重绘原图的橙色边框、人物或吉他。两张 `native-band-*.png` 通过既有遮罩、白色修补和人物比例参数导出，供本体同帧合成使用。对应源图、遮罩及导出工具同时提供。

角色、美术与商标权利属于各自权利人；代码许可不自动授予人物、美术的额外权利。皮肤清单中的代码许可声明与美术来源声明分别保留。

`native/KasumiBandOverlay.cs` 和 Diagnostics.exe 是历史素材导出工具，日常输入不运行。公开源码仅将其可选日志默认路径改为动态桌面路径，避免依赖开发机器目录；生产输入法源码不依赖该工具。
