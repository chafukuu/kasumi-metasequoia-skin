# 下载与使用

## 下载

打开 [v0.5.7 发布页](https://github.com/chafukuu/kasumi-metasequoia-skin/releases/tag/v0.5.7)，下载：

`kasumi-metasequoia-skin-v0.5.7-windows-x64.zip`

发布附件还包含 `SHA256SUMS.txt`。在 PowerShell 中可核对安装包：

```powershell
Get-FileHash .\kasumi-metasequoia-skin-v0.5.7-windows-x64.zip -Algorithm SHA256
```

GitHub 自动提供的 Source code (zip/tar.gz) 是源码包，不包含安装用的原生 Server 和 TSF 二进制。

## 适用条件

- Windows x64，已安装并正常工作的水杉输入法 v0.11.1 或 v0.11.2。源码以 v0.11.1 为基线；本机包检查覆盖注册版本 v0.11.2。
- 本包不是完整输入法安装器，不包含词库、输入法注册组件或 Watchdog。
- 安装器只接受清单列出的本体 Server 哈希；其他版本会停止，不能跳过检查。
- 需要正常管理员确认。Server 和 TSF 使用本地测试证书签名；这不代表证书会被其他电脑信任。未在全新系统验证 UIAccess，因此在高完整性应用上的悬浮显示可能不可用。
- 如提示缺少 VC++ 运行库，请使用[微软官方 v14 x64 可再发行组件](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)。

## 安装

1. 完整解压 ZIP，不要在压缩软件内部运行。
2. 双击 `Install.cmd` 并完成 Windows 的 UAC 确认。
3. 安装器会备份 Server、x86/x64 TSF、皮肤和配置，安装匹配的 Server 与皮肤，并执行 Server 运行检查。
4. 如果输出提示 TSF 更新已排队，请重启 Windows。TSF DLL 可能正被 Explorer 或其他应用加载；重启后，新 TSF 才会开始发送 LiveSD 键入活动。
5. 重启后在记事本或浏览器切换到水杉输入法，输入中文和英文，分别检查候选框和无候选状态下的小人。
6. 测试候选框增长、连续改宽、快速键入、拖动小人、点击反应 GIF、透明区域鼠标穿透，以及 Esc/失焦后的隐藏行为。

候选框出现时，小人的左侧移动范围额外开放 8 DIP。候选条增长时沿用本轮水平锚点，左边界不会随候选变长而右移。连续布局变化使用保留速度的平滑追踪。各键入节奏下的移动速度整体提高约 35–38%。五人挂件绘制在候选文字下方。

原有吉他摆动、每两个被接受字符发出两颗星星、蓝色/品红/黄色 2:1:1、删除输入后已发星星继续自然淡出等 v0.5.6 行为保持不变。

## 安装预览

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -WhatIf
```

`-WhatIf` 只检查安装计划，不需要管理员权限，也不修改输入法。需要自定义目录时直接运行 `Install.ps1` 并传入 `-ServerDirectory` 和 `-DataDirectory`；正常安装不要绕过哈希检查。

## 更新与回退

更新前保留旧下载包。每次真实修改前，安装器会生成独立备份，包含原始 Server、x86/x64 TSF、配置及皮肤文件。回退前先列出可用备份：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Restore.ps1 -List
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Restore.ps1 -Latest -WhatIf
```

在管理员 PowerShell 中去掉 `-WhatIf` 执行回退。若 TSF 更新尚在重启队列中，回退会重用该队列并将暂存内容改回原版；若更新已生效，则安排还原到下次 Windows 重启。不要手动删除安装器生成的 `.new` 暂存文件。

## 验证范围

本版 LiveSD 动作模型检查 21 组/13,846 个样本，原生窗口与 Direct2D 检查 89 项通过；候选变长时舞台锚点、左侧边界和连续变化追踪均有覆盖。上述测试不等于新版本在另一台电脑的实机验收。本便携安装器尚未在全新电脑完成真实安装、重启、TSF 加载和回退演练；真实应用宿主、物理多屏 DPI 与视觉帧率仍未确认，不承诺恒定 60 FPS。详见 [v0.5.7 验证记录](验证记录_v0.5.7.md)。

遇到问题时可附 Windows 版本、水杉版本、系统缩放与应用名；截图请先遮去私人输入内容。
