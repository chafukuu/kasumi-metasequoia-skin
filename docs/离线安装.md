# Windows x64 离线安装

[下载香澄输入法一体安装包（EXE，约 135 MiB）](https://github.com/chafukuu/kasumi-metasequoia-skin/releases/download/kasumi-20261123/Kasumi-IME-20261123-Windows-x64-Offline.exe)

1. 双击下载的 EXE，确认 Windows 显示的安装权限请求。
2. 按向导完成安装。在 Windows 输入法列表中切换到水杉输入法，可以用 `Win+空格` 切换。
3. 在记事本输入 `shuyu` 或 `jiaoji`，从候选栏选择 ∈ 或 ∩。按 `Shift+S` 再输入 `jihelun` 可以浏览集合论符号。

首次安装默认使用香澄皮肤，开启普通中文拼音符号混输，单 Ctrl 切换中英文。已有用户的配置会按水杉安装器的升级规则保留。升级后如果继续显示原皮肤，可在外观设置中选择 `kasumi-adaptive`，在实用功能中开启符号混输。

安装程序内含输入法主程序、32/64 位 TSF 注册组件、Watchdog、设置与面板、完整出厂词库、86 种数学符号、两档神经整句模型、LiveSD、COMBO 和 Microsoft Visual C++ x64 运行库。基础输入和这些本地功能均可断网安装使用。云候选和在线 AI 服务需要联网。

当前 LiveSD 使用按键事件计数，中文选词时每键计一次。达到 2 时显示 COMBO，退格或回车清零。符号名与拼音见[完整词表](../native-source/scripts/dictionary_build/math_symbols.tsv)。

安装程序需要管理员权限。普通电脑使用标准权限 Server；机器已信任此版本的签名并通过 Windows 验签时，安装器使用支持 UIAccess 的 Server。安装器本身未经公共代码签名，Windows 可能显示“未知发布者”。升级后已打开的应用可能需要重新打开才能加载新 TSF。

编译使用 Inno Setup 7 的 `KasumiOffline` 模式，安装载荷摘要见[文件清单](offline-payload-20261123.json)。已核对出厂词库、数学候选、皮肤和本机运行版本。尚未在全新 Windows 电脑上实测本安装包的安装、重启和卸载。
