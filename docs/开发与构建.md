# Development and build

## Source and version base

`native-source/` is the complete modified source snapshot based on Metasequoia IME `v0.11.1` (`dd018f79858314ed542a47c528608752b13bd261`). Vendor sources remain pinned to their recorded upstream commits. `patches/kasumi-native-v057.patch` is the complete source diff against that base. `docs/PROVENANCE.json` records the source base, artifact hashes, tested behavior, and verification limits.

The v0.5.7 package installs a matching native Server, skin, and x86/x64 TSF images. Supported detected IME versions are 0.11.1 and 0.11.2, and the installed Server must also match one of the explicitly listed hashes in the release manifest. TSF DLLs are backed up and scheduled for replacement at the next Windows restart when their hashes differ.

## Build the native Server

A source rebuild needs Windows x64, Visual Studio C++ Build Tools, Windows SDK, CMake, Ninja, vcpkg, and the `x64-windows-static-md` Boost libraries. From an x64 Native Tools / Developer PowerShell, set local dependency paths and run:

```powershell
$env:VCPKG_ROOT = 'D:\tools\vcpkg'
$env:BOOST_ROOT = 'D:\tools\vcpkg\installed\x64-windows-static-md'
.\tools\Build-Native.ps1
```

The script uses Ninja Multi-Config and builds the Server without installing or restarting the input method. The resulting hash may differ from the published binary, and the package installer accepts only the release manifest hash.

## Runtime behavior

- Native candidate artwork remains fixed-ratio; the candidate window owns text, artwork, and separators.
- LiveSD uses an optional negotiated TSF activity channel for English and Chinese typing. It follows the candidate card when present and uses a caret fallback without a card.
- The LiveSD model expands its left movement range by 8 DIP while a candidate is visible. Candidate growth preserves the session's initial horizontal stage anchor, and continuous resize retargeting retains velocity for smooth following.
- Typing cadence scales movement speed. Backspace and Delete do not generate typing pulses.
- The mascot supports idle, performance, turn, drag, click reaction, and transparent-region mouse passthrough. The PoppinParty pendant stays below candidate text.
- The guitar and typed stars remain native skin effects. Two accepted characters emit two stars; blue, magenta, and yellow use a shuffled 2:1:1 bag.

The v0.5.7 motion smoke covers 21 groups / 13,846 samples. The Direct2D host smoke covers 89 checks with controlled foreground, IPC ownership, and scale fixtures. Neither test substitutes for a fresh-machine install, real TSF host, physical multi-monitor or measured visual frame-rate acceptance.

## Package contents

`packaging/` is the portable installer template. The signed Server and x86/x64 TSF payloads are staged there while preparing the ZIP; `packaging/native/*.exe` and `*.dll` are intentionally excluded from Git. The ZIP includes these payloads with the matching skin, installer/rollback scripts, and hash manifest. The installer backs up the currently installed Server, TSF pair, skin, and config; it preserves dictionaries and input history. Do not change the manifest without regenerating the package checksums and validating every payload.

See [download and usage](下载与使用.md), [v0.5.7 verification](验证记录_v0.5.7.md), and [asset licenses](素材说明.md). The package uses a local test certificate; verify signature trust and UIAccess behavior on the target system before relying on elevation behavior.
